# Bureaucracy AI

AI-powered Indian Government Services Assistant.

## Core Features

- Retrieval-Augmented Generation (RAG)
- Local LLM inference
- Multilingual AI
- OCR and document intelligence
- Government service discovery
- Application and grievance assistance
- Source-grounded answers

## Technology

- Python
- FastAPI
- PostgreSQL
- pgvector
- Next.js
- Ollama
- PaddleOCR

## Development

Initial development focuses on Karnataka government services.

The system prioritizes open-weight models and local inference.
